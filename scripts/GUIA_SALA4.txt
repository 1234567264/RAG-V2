1. REQUISITOS A INSTALAR
----------------------------------------------------------------------
Abre la terminal en la carpeta principal e instala únicamente
las librerias necesarias para el procesamiento de imagenes e IA:

   pip install torch torchvision transformers pillow numpy

   (requirements.txt puede contener todas las dependencias del proyecto)


2. ARCHIVOS DEL MODULO (SALA 4)
----------------------------------------------------------------------
Asegurate de que tus archivos esten ubicados en estas rutas:

   webScraping-v2/
   │
   ├── data/
   │   ├── products.csv        <- CSV entregado por Sala 1 (orden de lectura)
   │   ├── images_normalized/  <- Banco canonico (imagenes del CSV; unica carpeta de busqueda)
   │   │                          (images_final/ fue eliminada en la migracion Hito 3)
   │   ├── embeddings_clip.npy / embeddings_openclip.npy / embeddings_siglip.npy
   │   │                       <- Indices del Hito 2 (Sala 4) sobre images_normalized/
   │   └── ids.npy             <- Salida: IDs en el mismo orden que los embeddings
   │
   ├── api/search_engine_hito2.py  <- Motor actual: fusion + reranking visual
   └── GUIA_SALA4.txt          <- Este archivo de guia

NOTA (Hito 3): los scripts standalone `buscar_por_imagen.py` y `search.py`
fueron eliminados en la limpieza de codigo. La busqueda se realiza a traves
de la API de Sala 3 (api/main.py).


3. ORDEN DE EJECUCION
----------------------------------------------------------------------

   PASO 1: Generar la base de vectores (Embeddings)
   Lee data/products.csv en su orden exacto, abre cada imagen, genera su
   embedding con el modelo openai/clip-vit-base-patch32 en lotes de 16,
   normaliza cada vector con L2 y guarda las dos rutas estandar:

      python generar_embeddings.py

   Al finalizar imprime el reporte de estado obligatorio:

      Productos en CSV: 1000
      Embeddings generados: 1000
      IDs guardados: 1000
      Dimensiones: 512
      Errores: 0


   PASO 2: Probar la busqueda visual por similitud
   Con la API de Sala 3 corriendo (en la raiz del proyecto):

      python -m uvicorn api.main:app --port 8000

   y en otra terminal:

      curl -X POST -F "file=@data/images_normalized/AIM-P001-001.jpg" \
           -F "modelo=fusion" http://localhost:8000/search/image/v2


4. PRUEBAS CON IMAGENES EXTERNAS (fuera de la biblioteca base)
----------------------------------------------------------------------
Para probar con imagenes externas (muy parecida, colores diferentes, no
relacionada) se usa la evaluacion integrada de 50 consultas con fusion:

   python scripts/compare_hito1_hito2.py --fusion

o se envian las imagenes una a una por curl al endpoint /search/image/v2
con modelo=fusion (el mas robusto).

NOTA SOBRE EL SCORE DE SIMILITUD
----------------------------------------------------------------------
El valor devuelto es un "score de similitud": una medida de cercania
matematica entre dos vectores dentro del espacio vectorial aprendido por el
modelo CLIP (similitud coseno, rango -1 a 1). NO es un porcentaje de
coincidencia, NI una confianza, NI la probabilidad de que sea el mismo
diseno. Un score alto indica que el modelo representa ambas imagenes de
forma parecida, no que el diseno sea identico.


5. VERIFICACION RAPIDA DE VECTORES (OPCIONAL)
----------------------------------------------------------------------
Para comprobar desde la terminal que el indice es consistente
(embeddings y ids alineados, vectores normalizados L2):

   python -c "import numpy as np; e=np.load('data/embeddings.npy'); i=np.load('data/ids.npy',allow_pickle=True); n=np.linalg.norm(e,axis=1); print('Embeddings:',e.shape); print('IDs:',len(i)); print('Normalizados L2 (max diff a 1):', round(float(abs(n-1).max()),6)); print('ID pos 0:', i[0])"
